Zone spacing

LPD-100162 · LPD-70090 · Figma

In the DXP Control Panel, the rows touch. The sidebar's Vertical Navigation was built with 44px items that carry the 4px of spacing inside the row, so there's no gap between rows or between groups. Items should be 40px, with the spacing outside them. As it stands, you can't tell where Sites ends and Users begins, and in the product sync we heard that Instance reads as separate from the rest of the panel.

Everything here is built with the Lexicon Vanilla Control Panel. The 6px rail, hover, active state and all four skins come from the kit. Only the row height and three gaps change: between items in a category, between categories in the same zone, and between System and Instance.

Neutral hover, zone-colored active

Default, hover and active come from .control-panel__item: hover uses --color-light and active adds the 6px rail. Inside a zone, only the active state takes the zone color. The kit has no focus style for this item, so this one uses the --focus-ring ring, drawn inward. None of this changes with the variant. Try all four skins.

Vertical Navigation fix for development

Sidebar items are 44px today because the spacing lives inside them. They should be 40px (--spacing-9), with the spacing set on the list: --spacing-2 (4) between items, --spacing-3 (8) between categories and --spacing-5 (16) between zones. At 40px, hover and active stop filling the gap, so each row stands on its own.
