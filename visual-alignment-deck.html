Touchpoint 04 · documentation

Learn runs its own set.

The 6 August session set the rule: docs referencing a feature use the functional product icon, so the page matches the screenshot beside it. Learn's UI icons come from Clay; its product icons do not. The set has no named owner in the group.

Expressive work inside the system.

  • Motion and depth, drawn in Lexicon geometry.
  • Purple only on AI, as the AI Visual Guide specifies.
  • Flat fills, so one file covers every surface.

One example of where the two positions already meet.

Touchpoints 05 & 06

Product UI, config and forms.

  • The flat set covers white, panel grey and dark mode from one file.
  • Decorative illustration sits with Comms; components, tokens and states with Lexicon.
  • Config and critical forms take nothing beyond the system. Nobody has argued otherwise.
