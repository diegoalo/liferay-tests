Card — Revamp 2026

Five card types on one shell. Each comes in a default and a dense layout, and Info and Navigation also have a horizontal one. The metadata sits in a frosted caption at the bottom, and the checkbox and file icon float in the corners.

Everything on this page is live: hover, select, open the actions menu, resize. The Screens tab puts every type in the DXP screen where it belongs.

Card with Info

    
Files with no graphical preview. Holds the most metadata of any card: title, subtitle, author and labels. Used in the document library, item selectors and management card grids.

    

      Default

      Dense

      Horizontal · folders and file lists

    

  


  

    
Card with Image

    
Files with a graphical preview. Images, PDFs, web content with a cover and page thumbnails, where the preview matters but the metadata still has to be readable over it.

    

      Default

      Dense

    

  


  

    
Card with User

    
People. Members, assignees and user management. The avatar, or its placeholder, and the name stay visible at a glance.

    

      Default

      Dense

    

  


  

    
Navigation Card

    
A destination. Product home, launchpads, dashboards and folder navigation. The whole card is the link, so it has no checkbox and no actions menu.

    

      Default

      Dense

      Horizontal

    

  


  

    
Gallery Card

    
Content where the preview tells items apart. Gallery views and visual multi-select. There's no caption, just the file-type sticker and optional labels over a blurred scrim. A click anywhere on the card toggles selection.

    

      Default

      Dense

    

  


  









  

    
Five DXP screens, one per card type. Each one works: select cards to switch the management toolbar to bulk mode, search to filter, change the view from the toolbar and use the ⋮ menus.

  


  
  

    

      
Files

      InfoImageInfo · horizontal
      
The document library. Folders are horizontal Info cards; files are Info cards when there's no preview and Image cards when there is. The view picker switches between cards, dense cards and a horizontal list.

    

    

  


  
  

    

      
Select image

      Image
      
The item selector opened from a web content field. Image cards keep the name and size readable so people can tell two similar photos apart. Pick one and press Add.

    

    

  


  
  

    

      
Product media

      Gallery · dense
      
A commerce product's images. Scanning beats metadata here, so the gallery card drops the caption. Click any photo to select it; the toolbar offers bulk actions.

    

    

  


  
  

    

      
Users and organizations

      User
      
Control Panel in card view. The avatar or its placeholder carries the identity; the caption holds the job title and role labels.

    

    

  


  
  

    

      
Product home

      NavigationNavigation · horizontal
      
The launchpad. Default navigation cards for the main areas, horizontal ones for recent places. Files and Users take you to those screens on this page.
